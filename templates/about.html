// WHAT I BUILD
AEROVISION started as a personal project to push the boundaries of image classification on domain-specific, limited datasets. The challenge: identify 5 visually similar fifth-generation fighter jets with high accuracy using only ~100 images per class. The result is a production Flask API backed by a fine-tuned EfficientNetV2S model, wrapped in a full-stack HUD-style web interface.

CORE LANGUAGE
PYTHON 3.10
Primary development language. Used for model training, data pipeline, Flask API, and all backend logic.
DEEP LEARNING FRAMEWORK
TENSORFLOW · KERAS
Deep learning framework powering model training and inference. EfficientNetV2S loaded via keras.applications.
MODEL ARCHITECTURE
EFFICIENTNETV2S
State-of-the-art CNN pre-trained on ImageNet. Fine-tuned via two-phase transfer learning. Native 384×384 input resolution for fine detail capture.
WEB FRAMEWORK
FLASK
Lightweight Python web framework serving the REST API. Handles image upload at /predict and jet info at /jet_info/<name>.
FRONTEND
HTML | CSS | JS
Pure vanilla frontend — zero frameworks. Custom HUD aesthetic built with CSS animations, SVG inline graphics, and ES6 JavaScript for API calls.
TYPOGRAPHY
ORBITRON · RAJDHANI
Google Fonts pairing: Orbitron (900) for display headers and HUD labels. Rajdhani for body text. Share Tech Mono for terminal and data readouts.
DATA PROCESSING
NUMPY · PILLOW
NumPy for array operations and image normalisation. Pillow for server-side image decoding, resizing to 384×384, and format conversion before inference.
VISUALISATION
MATPLOTLIB · SEABORN
Used for training analysis: accuracy/loss curves across 33 epochs, and the confusion matrix heatmap over the 5-class test set.
